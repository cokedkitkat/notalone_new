# NOT ALONE

A Next.js product-preview site exploring ideas for AI-powered companionship, games, and community connection.

## Local development

```bash
npm ci
npm run dev
```

Then open http://localhost:3000.

## Quality checks

```bash
npm run lint
npm run build
```

The GitHub Actions workflow runs both checks for pushes and pull requests.

## Product status

This repository currently contains a presentation site and illustrative UI demos. It does not implement authentication, live AI chat, voice features, community moderation, or end-to-end encryption. Do not use the preview for sensitive information.

See the in-site Privacy Notice, Terms of Use, and Safety & Product Status pages before publishing a production service.
